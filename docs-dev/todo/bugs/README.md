# Bugs

Defects, breaches of the invariants, and code that deviates from the documented intent. One
ticket per file; see [../README.md](../README.md) for the format, including the
[reproduction](../README.md#reproduction) every entry here carries.

The seven invariants in
[05-invariants.md](../../architecture/05-invariants.md) are not negotiable, so an entry here that
names one is a violation nobody approved, not a design choice. Idempotency and writing nothing
but a block's body are the two that a user cannot work around.
